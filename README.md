## Proyectos seleccionados

### Huffman Compressor Pro
Aplicación web para comprimir y descomprimir texto mediante el algoritmo de Huffman. Su documentación describe una separación entre frontend Next.js/React y backend FastAPI/Python, visualización del árbol y análisis de métricas de compresión.

**Tecnologías:** Next.js 14 · React 18 · TypeScript · Python 3.11 · FastAPI · Docker.

[Ver repositorio](https://github.com/Pudin0120/huffman-compressor-pro)

### Banking Portal API
Proyecto backend Java basado en Spring Boot. El archivo Maven declara Spring Boot 3.3.1, Java 17, Spring Security, JPA, validación, MySQL y Redis; el repositorio también incluye recursos Docker.

**Tecnologías:** Java 17 · Spring Boot 3.3.1 · Spring Security · JPA · MySQL · Redis · Docker.

[Ver código](https://github.com/Pudin0120/Portafolio/tree/main/Projects/BankingPortal-API-main)

### Inventory Management System
Aplicación Java con Maven para gestión de inventario y facturación. Su estructura documentada incluye entidades de productos, clientes y facturación, recursos SQL y componentes JavaFX.

**Tecnologías:** Java · JavaFX 11.0.2 · Maven · SQL.

[Ver código](https://github.com/Pudin0120/Portafolio/tree/main/Projects/inventory-management-system-main)
