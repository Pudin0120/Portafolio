# Cloud-Platform Selection Research

This folder preserves the cloud-platform selection workstream from the original project plan. It currently contains no cloud deployment template, infrastructure-as-code, environment configuration, or running cloud service.

A platform comparison should record the workload, deployment region, security requirements, identity/network boundaries, managed database needs, backups, observability, budget, and exit strategy. The final choice should be supported by a reproducible deployment and operational runbook, not only a feature comparison.

Do not commit cloud access keys, service-account JSON files, or deployment secrets to this repository. Treat this folder as a research placeholder until architecture decisions and deployment artifacts are added.
