# Device Online-Status Research

This folder marks the device-presence/online-status workstream. It currently contains no device-heartbeat implementation, broker configuration, backend service, tests, or build descriptor.

A reliable presence feature should define:

- A heartbeat interval and an explicit offline timeout.
- Unique device identity and authenticated device registration.
- Last-seen timestamps generated by the server.
- Connection state transitions and duplicate/replay handling.
- Behavior when clocks drift or networks reconnect.
- Monitoring and tests for missed/late heartbeats.

Do not infer device state from a single successful request or a client-provided timestamp. This folder remains a research placeholder.
