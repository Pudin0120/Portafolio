# Smart-Home Website Design Research

This folder identifies the website-design workstream in the original smart-home project plan. No website source, asset bundle, package manifest, or runnable frontend application is stored in this folder.

Use the UI assets and rendered design references under [related-assets](../../related-assets/) and the design requirements in [development-documents](../../development-documents/). Treat those materials as historical references rather than a verified, responsive implementation.

A future frontend should document its component structure, accessibility and responsive behavior, API contract, authentication model, and reproducible build.
